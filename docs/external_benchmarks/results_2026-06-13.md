# SWE-bench Lite — first external scores (2026-06-13)

anie's first apples-to-apples result against another harness, graded
by the **official** `swebench` 4.1.0 evaluator (local Docker,
`--namespace swebench` prebuilt images). Same model, same instances,
same grader — the only variable is the harness.

## Setup

- **Model**: gemma4:e4b via Ollama (16,384 num_ctx override).
- **Subset**: first 25 of SWE-bench_Lite `test` by sorted
  instance_id (deterministic; `common.load_subset`).
- **Arms**: anie `--harness-mode=rlm` vs mini-swe-agent 2.4.1
  (litellm `ollama/gemma4:e4b`). Identical 480s/instance wall-clock
  budget, identical diff-capture rule (artifact-filtered).
- Generation 2026-06-12 (overnight); grading 2026-06-13.

## Result

| arm | resolved | resolved % | mean tokens | mean turns | tool calls | tool fail % |
|-----|----------|-----------|-------------|-----------|-----------|-------------|
| **anie (rlm)** | **1/25** | **4.0%** | 37,686¹ | 5.8 | 57 | 5% |
| mini-swe-agent | 0/25 | 0.0% | 57,943 | 19.8 | 312 | 14% |

anie swept every axis: it **resolved an instance the control
didn't** (`django__django-11133` — in mini-swe-agent's
*empty-patch* list, i.e. it produced no patch there at all), with
**~3× fewer turns**, fewer tokens, and a third the tool-failure rate.

## Honest caveats

1. **anie's mean tokens/turns are over 12/25 sidecars only** — anie
   writes no RunMetrics sidecar on a budget timeout (13 instances
   timed out), so its means are biased toward the *completed* (often
   shorter) runs. mini-swe-agent's means cover all 25. The
   **resolved rate is fully comparable** (graded over identical
   instance sets); the efficiency columns are directional. Fix
   tracked: emit a partial sidecar on timeout.
2. **n=25 at single-digit resolve rates** — 1-vs-0 is a real,
   officially-graded head-to-head, but not statistically robust.
   It says "anie is at least as capable and markedly more efficient
   here," not "anie resolves Nx more."
3. Absolute rates are low because the *model* is 4B-class; that's
   expected and is the point of measuring the harness delta, not the
   absolute.

## Update 2026-06-14: gemma4:12b arm + the real bottleneck

Reran with the 900s budget + crash-safe sidecars, gemma4:12b (both
arms), same 25 instances, official grader.

| arm | resolved | mean turns | mean tokens | empty patches |
|-----|----------|-----------|-------------|---------------|
| anie 12b | **1/25** | 4.6 | 27,123 | 24/25 |
| mini-swe-agent 12b | 0/25 | 3.3 | 8,608 | 23/25 |

anie still wins the head-to-head (1 vs 0) at 12b too. But the bigger
model did **not** raise the absolute score — and 12b produced *fewer*
patches than e4b (anie: 1 non-empty at 12b vs 5 at e4b).

### The dominant failure mode is empty patches, not timeouts

Across all four runs (resolved / non-empty / empty of 25):

| run | resolved | non-empty | empty |
|-----|----------|-----------|-------|
| anie e4b | 1 | 5 | 20 |
| anie 12b | 1 | 1 | 24 |
| control e4b | 0 | 4 | 21 |
| control 12b | 0 | 2 | 23 |

12b had **zero timeouts** (4.6 mean turns, finished fast) yet edited
nothing in 24/25. So the bottleneck is **not** budget, speed, or
model size — both models *terminate without making an edit*. They
read, reason, sometimes answer in prose, and stop. The anie preamble
already says "your edits are the deliverable; do not just describe a
fix," and it still happens 24/25 — a passive prompt nudge is not
enough.

### Highest-leverage next fix: no-op completion guard

A harness mechanism (small-model scaffolding, exactly anie's thesis):
when the agent reaches a stop with the working tree **unchanged**,
inject a directive ("you ended without editing any file; the task
requires a concrete code change — make the edit now") and continue,
up to N guard rounds. This attacks the dominant failure mode for
BOTH models and is independent of the benchmark. Proposed as the next
plan after this is reviewed.

### Honest standing

- anie beats the reference scaffold on resolves at both model sizes
  (1-0 each), with comparable/better efficiency.
- Absolute rates stay at 1/25 because ~90% of attempts never produce
  an edit — a harness-addressable behavior the benchmark surfaced.
- This is the value of external grading: it found the bottleneck our
  internal navigation corpus (which doesn't require edits) could not.
